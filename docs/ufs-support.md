# v1.7.0 MU300 UFS 安装、卸载与受限 ext4 修复说明

## 包身份与应用集成

Android 包名保持 `top.linote.owrtinstaller`，原有 Activity、服务、权限、偏好设置、应用数据路径及既有功能均保留。应用安装后的显示名称为 `OpenWrt 安装器`。正式 APK 使用项目既有正式签名，以支持对相同签名的已安装版本进行覆盖升级。签名密钥和密码不包含在源码包或交付文件中。

如需复现可更新既有安装的构建，请在运行 `build.sh` 前将 `OWRT_SIGNING_DIR` 指向项目已有签名目录；未提供该目录时，脚本生成的本地备用签名不能用于升级由其他密钥签署的安装。

## UFS 支持范围

此版本的 MU300 UFS 安装、重装、卸载与空间回收仅适用于 `mu300-openwrt-25.12.5-r20261027.135818-g0043a5d8-s5351d2bc-k.zip`。Android 端使用包内经固定 SHA-256 校验的 storage library 做只读存储发现和 UFS 身份核验；离线卸载镜像也携带同一已校验库。GPT logical block 支持 512 或 4096 字节，但容量、分区几何和回收计划统一以 Android sysfs 的 512-byte sectors 表示，并在 GPT 读写时显式换算。

1.6.9 在第四步开始任何只读预检之前核对已探测的设备型号；若安装包与机型不匹配或设备身份尚未确认，会安全停止并说明原因，不继续设备端检查或分区操作。

MU300 UFS 独立内置分区安装及重装行为保持不变，包括空闲空间路径和该安装包脚本支持的两阶段准备/续装（先准备、按提示重启后续装）。原有 eMMC 内置安装、E5 卸载和 TF 卡流程保持不变。

UFS 卸载只接受同一已识别 MU300 UFS 设备上唯一的 `mu300root` 与 `userdata`，还需通过启动镜像、分区归属和 OpenWrt 安装证据核验。若 `mu300root` 紧邻 `userdata`，可把其范围并入 userdata；若不相邻，只清除 OpenWrt 分区项并把该分区释放为空闲空间，不跨越或覆盖中间分区。

### ext4 journal 修复

若正常卸载检查只因 ext4 `needs_recovery` 停止，应用会先独立验证 MU300 UFS 身份、`sda75`/`mu300root` 标签、GPT 主备表与分区 GUID/范围、启动槽和 OpenWrt 安装证据。入口只接受已核验的精确布局：`state=0x0001`、`incompat=0x00000046`（唯一未支持位为 `needs_recovery`）、4096-byte block、`error_count=0`、内部 journal。还要求没有 `data=journal` 配置、目标未挂载/无 holder，工具哈希正确且可暂存于 RAM `/dev`。

用户输入“修复 mu300root journal”后，只执行 `e2fsck -p -E journal_only`；随后重新读取 ext4 身份并运行完整只读 `e2fsck -f -n`，最后再调用原来的 `Uninstall.prepare`。外置 journal、文件数据日志模式、其它特性位、错误计数、挂载状态、设备或几何变化、非 0/1 修复返回码、只读检查非 0 均会停止；不会扩大到 `-y`、全盘 fsck、格式化、扩容或重试。事务每个阶段均写入并从本机记录回读，启动中的不确定操作不会自动重放；重新连接时只做只读核验。只有所有原有卸载证据通过后才显示原卸载计划，用户仍须另行完成卸载确认。

没有原始安装记录时，原有启动镜像和 OpenWrt 文件标记证据仍是独立门槛；修复入口不导入用户备份 ZIP，也不降低这项要求。该路径只对 `mu300root` 内部 ext4 journal/元数据写入；维护工具、日志与临时记录在本机或设备 RAM `/dev`，不写 GPT、boot、misc、userdata 或其它分区。

GPT 主备副本、usable-LBA 范围、表项 CRC、分区类型/GUID/名称、盘符/LUN 归属、512/4096-byte 对齐和 byte/LBA 换算均须通过严格边界检查。身份、安装证据或布局不唯一、越界、错位、哈希不符或逻辑块大小不支持时均拒绝；格式化 Android 数据的确认不能绕过这些拒绝。其他 MU300 安装包版本未经过适配时，不应使用其进行 UFS 卸载或 UFS 内置安装。

## 验证边界

验证涵盖本地 APK 构建与包名/版本/签名验证、UI/版本静态断言、minSdk 26 API 扫描、UFS 身份和 512/4096-byte 合成 GPT 测试、卸载布局/越界/拒绝测试、受限 ext4 recovery 纯逻辑测试，以及 command-level 模拟生命周期回归。模拟未连接设备；UFS 与 ext4 recovery 测试使用本地合成数据。用户上传备份 ZIP 未被修改或执行。此次工作没有连接或写入真实设备，没有格式化、刷写或重启设备，因此不能据此声称真实 UFS 设备上的修复或卸载已验证。
